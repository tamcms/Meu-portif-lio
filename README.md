## :purple_heart: Portfólio Pessoal

Este repositório contém o código-fonte do meu portfólio pessoal, desenvolvido com o objetivo de apresentar minhas habilidades, meus conhecimentos e minha evolução na área de tecnologia. 
O projeto foi criado utilizando HTML5 e CSS3, com foco em um design minimalista, organização visual e navegação intuitiva.

## :computer: Tecnologias utilizadas
* HTML5 — estruturação e organização do conteúdo.
* CSS3 — estilização, layout, responsividade e efeitos visuais.

## :dart: Objetivos do projeto

* Praticar e aprimorar meus conhecimentos em HTML e CSS.
* Desenvolver minha identidade profissional na área de tecnologia.
* Construir meu portfólio para oportunidades de estágio e crescimento profissional.
